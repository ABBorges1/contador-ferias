# contador-ferias

Contagem regressiva para as férias de fim de ano: **16/12/2026 às 17:00:00**.

- **Dias corridos:** dias, horas, minutos e segundos até o fim do último expediente.
- **Dias úteis:** desconta fins de semana e feriados nacionais, do estado de São Paulo e de Franca-SP. O dia de hoje conta até as 17:00.
- **Comemoração:** na hora exata, a tela mostra fogos, confete, buzina, torcida e um hino de vitória original sintetizado no navegador. Dá para trocar a música por um MP3 seu.

## Como usar

Abra o `index.html` em qualquer navegador. Para a festa ter som, clique em **Ativar som da festa** e deixe a aba aberta no dia 16/12.
